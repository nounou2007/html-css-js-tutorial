# Mini Projects Collection

A collection of small front-end projects built with **HTML, CSS, and JavaScript**. Each folder is a standalone project — no build tools or dependencies required, just open the `index.html` in a browser.

## Projects

| Project | Description |
|---|---|
| [BMI Calculator](./BMI%20calculator) | Calculates Body Mass Index from user-input height and weight, with category feedback (underweight, normal, overweight, etc.). |
| [Currency Converter](./currency%20converter) | Converts an amount between currencies using exchange rate data. |
| [Random Password Generator](./random%20password%20generator) | Generates secure, random passwords based on user-selected length and character options (uppercase, numbers, symbols). |
| [Sign Up Page](./sign%20up%20page) | A styled sign-up form with client-side input validation. |
| [Slider](./slider) | An interactive image/content carousel slider with next/previous navigation. |
| [To Do List](./to%20do%20list) | A task manager to add, complete, and remove to-do items, with styling touches. |

## Tech Stack

- **HTML5** — structure/markup
- **CSS3** — styling and layout
- **JavaScript (Vanilla)** — interactivity and logic

No frameworks, libraries, or package managers involved — everything runs directly in the browser.

## How to Run

1. Clone the repo:
   ```bash
   git clone https://github.com/nounou2007/<repo-name>.git
   ```
2. Open any project folder.
3. Open its `index.html` file directly in your browser (double-click, or right-click → Open With → Browser).

No installation or server setup needed.
